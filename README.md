# Crust Pizza Co. - Chicago-Style Thin Crust Pizza Landing Page

Réplica idéntica y de alta fidelidad de la landing page artesanal y retro de **Crust Pizza Co.**, construida con **Next.js 16**, **Tailwind CSS v4** y **TypeScript**.

## 🍕 Características del Proyecto

- **Estilo Retro Artesanal**: Paleta de colores crema, naranja tostado y carbón oscuro, con texturas de fondo y detalles de cinta adhesiva ("washi tape").
- **Logo Circular "CRUST PIZZA CO."**: Componente SVG personalizado con estilo de sello vintage para header, footer y marca de agua en pizza.
- **Hero Section**: Fotografía de pizza compartida en mesa rústica de madera con placa oscura superpuesta y cinta adhesiva kraft.
- **Our Menu**: Grid de platos destacados (Chicken Parm, Chicken Alfredo, Spaghetti & Meatballs, Baked Mac & Cheese) con tarjetas redondeadas, etiquetas de precio y selector de pedidos.
- **Home of Chicago-Style Thin Crust**: Sección explicativa con cuadrícula 3x2 de badges de servicios y fotos estilo Polaroid con cinta adhesiva en las esquinas y rotaciones sutiles.
- **Ways to Enjoy**: Fotografía cenital de pizza con sello central y tarjetas informativas oscuras de premios y promociones ("Kids Eat Free").
- **Comunidad y Why Choose Us**: Sección comunitaria con ilustración vectorial y galería de 6 fotos gastronómicas con lightbox interactivo.
- **Franquicias y CTA**: Fotografía exterior del restaurante al atardecer y accesos directos a locaciones, tarjetas de regalo y recompensas.
- **Modal de Pedido Interactivo**: Sistema funcional para ordenar en línea (Pickup o Delivery), consultar locales y solicitar información de franquicia.
- **100% Responsivo**: Totalmente adaptable a móviles, tablets y pantallas de escritorio con navegación drawer táctil.

## 🛠️ Tecnologías

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Estilos**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconografía**: [Lucide React](https://lucide.dev/) + Iconos vectoriales personalizados
- **Tipografías**: Google Fonts (`Oswald` & `Plus Jakarta Sans`)

## 🚀 Inicio Rápido

1. Instalar dependencias:
```bash
npm install
```

2. Ejecutar servidor de desarrollo:
```bash
npm run dev
```

3. Abrir en el navegador:
```
http://localhost:3000
```
